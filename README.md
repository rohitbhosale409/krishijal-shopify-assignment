# 🌱 KrishiJal Shopify Coding Assignment

A fully responsive **Shopify Online Store 2.0** theme developed for **KrishiJal** as part of a Shopify coding assignment.

KrishiJal is an innovative agricultural solutions brand focused on improving soil health and crop productivity through science-backed, eco-friendly products.

The website is built using **Shopify Liquid, HTML5, CSS3, JavaScript, and Shopify Online Store 2.0 architecture**, with reusable sections and Theme Editor customization support.

---

## 🚀 Project Overview

The objective of this assignment was to create a modern, responsive, and dynamic Shopify homepage based on the provided KrishiJal brand brief.

The implementation focuses on:

- Clean and maintainable Shopify Liquid code
- Responsive design
- Reusable Shopify sections
- Shopify Theme Editor customization
- Mobile-friendly navigation
- Product-focused layout
- Interactive JavaScript components
- SEO-friendly structure
- Performance-conscious implementation
- Desktop, tablet, and mobile compatibility
